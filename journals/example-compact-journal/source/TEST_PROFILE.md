# 虚构紧凑格式测试投稿要求

本文件只用于 Academic Submission Compiler 期刊切换测试，不代表任何真实期刊。

全文文字颜色为黑色。论文标题采用小二号黑体居中。作者使用四号楷体居中，单位使用小四号宋体居中。中文摘要和关键词使用五号宋体，英文使用 Times New Roman。正文采用五号仿宋，英文和数字采用 Times New Roman，1.5 倍行距，两端对齐，首行缩进 2 字符。一级标题用四号黑体，二级标题用小四号黑体，三级标题用小四号楷体。脚注和参考文献采用五号宋体。页边距上下 20 毫米、左右 25 毫米。

摘要不超过 300 字，关键词 3 至 6 个，正文 150 至 20000 字。本测试 profile 不要求匿名审稿。
